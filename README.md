# Bộ cài Google Ads Pro

Repo công khai, **không chứa bí mật**: muốn cài phải có **mã mời** (gap1.…) do người quản lý gửi riêng cho từng người.

- Mac: mở Terminal, dán dòng lệnh bạn nhận được (`curl … install.sh | bash -s gap1.…`).
- Windows: mở Command Prompt (cmd), dán dòng lệnh bạn nhận được (`powershell … 'gap1.…'`).

Repo được cập nhật bằng `python3 tools/invite.py publish` từ repo chính (manquocviet/google-ads-pro); không sửa tay ở đây.
